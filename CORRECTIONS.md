# Corrections and versions

Report a suspected error by opening an issue on the repository. Confirmed
errors are recorded here with the date, the affected version, and the fix.

- A correction that leaves the stated results intact is made in the living
  repository and in a new version.
- If a stated result is wrong and cannot be repaired, it is withdrawn here and
  in the README, and the affected versions are named.
- A superseding version is linked from here and from the README.
- Released tags and archived versions are never altered. Their DOIs continue to
  resolve to the original files.
